# Challenges in Machine Learning

Machine Learning has several challenges that affect how accurately a model learns, makes predictions, and performs in real-world applications.

## 1. Ten Challenges in Machine Learning

| No. | Challenge | Meaning |
|---|---|---|
| 1 | Data Collection | Getting sufficient and relevant data for training. |
| 2 | Insufficient Data | Not having enough training examples to learn properly. |
| 3 | Non-Representative Data | Training data does not represent the real-world population. |
| 4 | Poor Quality Data | Data contains missing values, duplicates, errors, or noise. |
| 5 | Irrelevant Features | Input variables that do not contribute useful information to predictions. |
| 6 | Overfitting | Model memorizes training data instead of learning general patterns. |
| 7 | Underfitting | Model fails to learn the actual patterns in the data. |
| 8 | Software Integration | Connecting ML models with existing software applications. |
| 9 | Deployment and Learning | Making models available for real-world use and keeping them updated. |
| 10 | Cost and MLOps | Managing infrastructure, monitoring, maintenance, and operational expenses. |

---

## 2. Important Definitions to Remember

| Term | Quick Definition |
|---|---|
| **Feature** | An input variable used by a machine learning model to make predictions. |
| **Feature Selection** | Selecting the most useful input variables from existing features. |
| **Feature Engineering** | Creating new features or transforming existing features to improve model performance. |
| **Data Preprocessing** | Cleaning and preparing raw data before using it to train a model. |
| **Overfitting** | Model performs well on training data but poorly on unseen data. |
| **Underfitting** | Model performs poorly on both training and unseen data. |
| **Generalization** | Ability of a model to perform well on new, unseen data. |
| **Offline Learning** | Model is trained in batches and updated through retraining. |
| **Online Learning** | Model learns incrementally as new data arrives. |
| **Deployment** | Making a trained model available for real-world use. |
| **MLOps** | Managing the machine learning lifecycle in production, including deployment, monitoring, and maintenance. |
| **Model Drift** | Model performance degrades when real-world data or patterns change over time. |

---

## 3. Important Comparisons

### 3.1 Overfitting vs Underfitting

| Overfitting | Underfitting |
|---|---|
| Memorizes training data. | Fails to learn enough patterns. |
| High model complexity. | Low model complexity. |
| Low training error. | High training error. |
| High testing error. | High testing error. |
| Poor generalization. | Poor generalization. |

**Remember:**
- Overfitting = Learning too much from training data, including noise.
- Underfitting = Not learning enough from training data.

### 3.2 Offline Learning vs Online Learning

| Offline Learning | Online Learning |
|---|---|
| Trains in batches. | Learns incrementally. |
| Requires retraining to incorporate new data. | Can update as new data arrives. |
| Suitable when updates are periodic. | Useful when data changes continuously. |
| Training happens separately from regular predictions. | New data can be used for continuous updates. |

### 3.3 Feature Selection vs Feature Engineering

| Feature Selection | Feature Engineering |
|---|---|
| Selects existing useful features. | Creates or transforms features. |
| Removes irrelevant or unnecessary features. | Creates more useful information from existing data. |
| Does not create new features. | Can create new features. |

---

## 4. Quick Revision

- **Feature:** Input variable used by a model.
- **Feature Selection:** Choosing useful existing features.
- **Feature Engineering:** Creating or transforming features.
- **Data Preprocessing:** Cleaning and preparing data.
- **Overfitting:** Good training performance, poor testing performance.
- **Underfitting:** Poor training and testing performance.
- **Generalization:** Performing well on unseen data.
- **Offline Learning:** Train in batches.
- **Online Learning:** Learn incrementally.
- **Deployment:** Making a model available for real-world use.
- **MLOps:** Managing ML models in production.
- **Model Drift:** Performance decreases because real-world data changes.
