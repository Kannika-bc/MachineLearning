10 Challenges in Machine Learning
No.	Challenge	Meaning
1	Data Collection	Getting sufficient and relevant data
2	Insufficient Data	Not having enough training examples
3	Non-Representative Data	Data does not represent the real-world population
4	Poor Quality Data	Missing values, duplicates, errors, noise
5	Irrelevant Features	Unnecessary input variables
6	Overfitting	Model memorizes training data
7	Underfitting	Model fails to learn actual patterns
8	Software Integration	Connecting ML models with real applications
9	Deployment and Learning	Making models available and keeping them updated
10	Cost and MLOps	Managing infrastructure, monitoring, maintenance and expenses

Important definitions to remember
Term	Quick definition
Feature	Input variable used by a model
Feature Selection	Selecting useful input variables
Feature Engineering	Creating or transforming useful features
Data Preprocessing	Cleaning and preparing raw data
Overfitting	Performs well on training data but poorly on unseen data
Underfitting	Performs poorly on both training and unseen data
Generalization	Ability to perform well on unseen data
Offline Learning	Model is trained in batches and updated through retraining
Online Learning	Model learns incrementally from incoming data
Deployment	Making a model available for actual use
MLOps	Managing the ML lifecycle in production
Model Drift	Model performance degrades as real-world data changes

Important comparisons
1. Overfitting vs Underfitting
Overfitting	Underfitting
Memorizes data	Doesn't learn enough
High model complexity	Low model complexity
Low training error	High training error
High testing error	High testing error

2. Offline Learning vs Online Learning
Offline	Online
Trains in batches	Learns incrementally
Requires retraining to update	Can update as new data arrives
Suitable when updates are periodic	Useful when data changes continuously

3. Feature Selection vs Feature Engineering
Feature Selection	Feature Engineering
Select existing features	Create or transform features
Removes irrelevant features	Creates more useful information
